WIM & CO — Playground deployment package

Files:
- index.html              Updated WIM & CO homepage with an Archive entry linking to /playground/
- playground/index.html   Your standalone interactive playground

Deploy:
1. Unzip this package.
2. Open your GitHub repository for the WIM & CO Cloudflare Pages site.
3. Upload/replace the root index.html with this package's index.html.
4. Create a folder named `playground` in the repository and upload its index.html there.
5. Commit the changes. Cloudflare Pages should deploy automatically.

The URL should resolve as https://wimco.se/playground/ after deployment and DNS/Pages routing are active.
Keep a backup of your current homepage before replacing it.
